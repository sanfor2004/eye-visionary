# Changelog

All notable changes to Eye Visionary are documented here.

## [Unreleased]

### Added

- Offline-first model manifest and download/verification scripts.
- Lazy local providers for Florence-2 captioning and InsightFace face analysis.
- Deterministic and realistic two-person test fixtures.
- Architecture, data model, API, processing, development, usage, privacy, operations, and model licensing documentation.
- Public-repository contribution, security, conduct, and support policies.

### Notes

- Actual model weights are intentionally not committed. Run the documented bootstrap command while online.
- Full model inference remains dependent on local model cache availability.
