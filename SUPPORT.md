# Support

Start with the [README](README.md) and the [documentation index](docs/README.md). For setup problems, include the operating system, Python version, command, and complete error message.

Do not include private images, face vectors, GPS coordinates, credentials, or model cache files in issues or support requests. Use the generated fixtures when reporting a reproducible image-processing problem.

Use:

- GitHub Issues for reproducible bugs and documentation corrections.
- Discussions for design questions and usage help.
- Private security reporting for vulnerabilities; see [SECURITY.md](SECURITY.md).
