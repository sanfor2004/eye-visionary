# Code of Conduct

## Our standards

We expect contributors to be respectful, constructive, technically honest, and mindful of privacy. Welcome different backgrounds and viewpoints, focus on the work, and give feedback that is specific and actionable.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, publishing private data, and intentionally exposing biometric or location information.

## Enforcement

Report concerns privately to the repository maintainer through GitHub's private contact or security-advisory mechanisms. Maintainers may edit or remove contributions, pause participation, or block accounts when necessary to protect the community.

This code of conduct applies in repository issues, pull requests, discussions, and project-related communication.
