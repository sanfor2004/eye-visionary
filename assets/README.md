# Test assets

- `two_people_generated.png` is a generated, consent-safe realistic image for testing the real face detector and captioner. It is not a real person's photograph.
- `synthetic_two_people.png` is generated by `python scripts/create_synthetic_fixture.py` and is intended for deterministic hashing, metadata, and mocked-provider tests. Drawn faces are not expected to be detected reliably by a production face model.
